# Student Performance Prediction System

## Project Overview

This project uses Machine Learning to predict whether a student will Pass or Fail based on:

* Study Hours
* Attendance
* Previous Score

## Technologies Used

* Python
* Pandas
* Scikit-learn
* Git
* GitHub

## Project Structure

Student-Performance-Prediction/

├── src/

│ └── student_prediction.py

├── models/

│ └── model.pkl

├── README.md

└── requirements.txt

## Steps Performed

1. Load Dataset
2. Explore Dataset
3. Preprocess Data
4. Train Machine Learning Model
5. Evaluate Model Accuracy
6. Save Model
7. Push Project to GitHub

## Output

The model predicts whether a student will Pass or Fail based on input values.
